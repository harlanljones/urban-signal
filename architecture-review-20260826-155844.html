Problem

One Metro registration leaks across shared imports, configuration, aliases, dashboard metadata, invariant tables, and a registry that manually copies leaf declarations.

Solution

Deepen each existing Metro module as the locality for its complete registration; let the registry implementation derive mechanical projections without changing downstream behavior.

Wins

  • locality: one Metro module
  • leverage: every projection follows
  • tests cross one interface
  • spine contention falls sharply
ADR fit: implements ADR-0001’s own highest-value refactor signal and preserves ADR-0007’s separate-registration model.

Problem
