# Wave 3 Phase-0 probe — Corpus Christi, TX (US-265)

**Date of probe: 2026-08-31 (UTC).** Every host, catalog, watermark, and row below was probed live that day. Catalog `metadata_modified` / Hub `modified` timestamps were never used as evidence. "Live" means a newest-row read (watermark descending) returned fresh data with row-level verification. All ArcGIS `query` probes use `resultRecordCount` bounded reads and include layer-index disambiguation.

Linear: **US-265**. Ticket hint: Accela + Nueces GIS, Fit Medium. Region: South Central / Coastal Bend, Est pop ~430K (city ~317K; Nueces County seat, FIPS 48355). The prior Southwest & Mountain West sweep (2026-08-30) marked Corpus Christi **Tier 3 DEFER** (Dynamic Portal / EnerGov, no bulk REST). This probe **re-verifies** at Socrata, Hub DCAT, ArcGIS Server, and AGOL org layers with row-level watermark/DESC/count/geocode checks.

Success criterion (ADR 0004): a feed is registrable if it is *live* and either natively geocoded **or** address-geocodable. Tier 1 = live + native geocode; Tier 2 = live + address-only (ADR-0004 geocoder); Tier 3 = stale / no portal / wrong grain / vendor-locked without bulk API / Salesforce-gated.
