# US-434: Cartographic identity for dashboard map

## Summary

Gave the dashboard map a stronger cartographic identity beyond the stock Esri dark-gray tiles. The basemap no longer reads as a generic overlay — it sits inside the dark canvas, framed as a designed instrument, with the H3 hex field as the clear hero.

## Changes

- `apps/api/src/serving/dashboard.py` — CSS: Added a radial-gradient vignette overlay (`::after` pseudo-element) on `.map-container` that darkens the edges and draws the eye to the center where H3 data lives. Added a subtle border frame to the map container (1px at 6% opacity slate) so the map reads as a designed panel rather than a floating window.

- `apps/api/src/serving/dashboard.py` — MAP_STYLE: Reduced Esri base tile `raster-opacity` from 0.88 to 0.70, `raster-saturation` from -0.45 to -0.55, and `raster-brightness-max` from 0.82 to 0.65. Reduced label layer `raster-opacity` from 0.50 to 0.35 and `raster-brightness-max` from 0.75 to 0.55. The basemap now recedes into the ink canvas instead of sitting on top of it.

- `apps/api/src/serving/dashboard.py` — H3 hex fill opacity: Boosted the minimum opacity from 0.42 → 0.50, mid from 0.6 → 0.70, high from 0.88 → 0.92. Extrusion opacity from 0.88 → 0.92. With the basemap subdued, the hexes command more visual weight.

- `apps/dashboard/public/index.html` — Regenerated by `python3 scripts/export_dashboard.py` to keep the static copy in sync.

## Testing

- Ran `python3 scripts/verify_cicd_preflight.py` — all gates green (interlock, cross-ref, product facts, lint, export, ruff)
- The interlock gate's `TestDashboardWiring` validates the static copy matches `get_dashboard_html()`

## Notes

- The vignette uses `pointer-events: none` and sits at `z-index: 2` so it does not interfere with map interactions (clicks, pan, zoom) or the floating controls (z-index 50+).
- The Esri tiles remain fully functional and legible — road geometry, water bodies, and parks are still distinguishable, especially at metro zoom levels.
- The `fill-opacity` ramp is duplicated in two places (`setupGridLayers` and `updateMetricVisuals`) — both were updated in sync.
