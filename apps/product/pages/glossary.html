Plain-language definitions, each pointing at where the thing is implemented or documented. No entry on this page exists only in copy — if a term cannot be traced, it does not ship.

SPATIAL INDEX H3 resolutions 7 / 8 / 9

Every event lands on Uber’s H3 hexagonal grid three times at once. A resolution-7 cell covers roughly 5.2 km² and answers metro-scale questions; resolution 8 (~0.74 km²) matches submarket grain; resolution 9 (~0.10 km²) is the neighborhood cell where block-scale movement shows up first. One record, three comparable scales.

REGISTRY UNIT Division

The top spatial grouping inside a metro: a borough in New York (Manhattan is one), a city division elsewhere (Chicago runs six). Each division declares a center, a bounding box that must nest inside the metro’s, and the roster of submarkets it contains.

READ MORE: Cities · apps/api/src/spatial/city_registry.py

REGISTRY UNIT Submarket

A named corridor inside a division — SoHo, Tribeca, River North — declared in the registry with metadata rather than guessed from a heatmap. Features aggregate to this grain, so “the submarket is compounding” means one of these declared units, not an analyst’s highlighter.

READ MORE: Cities / NYC · apps/api/src/spatial/submarkets.py

SCORE LIMS — Leading Indicator Momentum Score

The composite momentum measure built from four time-decayed municipal signal families across 6-, 12-, and 18-month horizons — composition, decay, and thresholds documented on the Methodology page.

READ MORE: Methodology

INGESTION Watermark column

The timestamp column each feed declares — issuance_date for permits, created_date for 311 — that sync reads as a high-water mark, so restarts resume where they left off instead of re-paging from the start. Comparison is typed, so a malformed row cannot become the newest watermark by accident. Every feed’s column is exposed in facts.json.

READ MORE: facts.json (feeds.*.watermark_col) · apps/api/src/producers/watermarks.py

FEED FAMILY SLA feed

Hospitality licenses: activations from the New York State Liquor Authority, plus Chicago business licenses. New licenses trace where commercial foot traffic is expected before leases are public — one of the four ingredients of license activity in LIMS.

READ MORE: Methodology, license activity · apps/api/src/producers/sla_licenses_producer.py

INGESTION Snapshot mode

Some municipal datasets publish as full-table snapshots with no reliable incremental timestamp. The registry declares those feeds ingestion_mode: snapshot: each refresh diffs IDs against the previous full pull instead of trusting a watermark, so nothing slips through between refreshes.

READ MORE: System, ingestion contracts · city_registry.py (ingestion_mode)

INGESTION Year-sliced feeds

Jurisdictions that publish one dataset layer per calendar year instead of one growing table. The registry stores the year map (endpoint_by_year) and resolves today’s endpoint to the current year’s slice — rotating automatically at each New Year rather than silently reading last year’s file.

READ MORE: city_registry.py (endpoint_by_year)

SIGNAL Catalyst alert

Fires when a cell’s LIMS reaches 85.0 or higher — the LIMS_THRESHOLD default, published in configuration like every other dial. The dashboard’s catalyst feed uses the same threshold; there is no private number.

READ MORE: Methodology, public thresholds · apps/api/src/config.py (lims_threshold)

ENFORCEMENT Interlock gate

The test suite (pytest -m interlock) that enforces how a city joins: closure, completeness, containment, registry-export match, and dashboard wiring. Registration is not done when the registry accepts an entry — it is done when the city appears on the map. A registered metro missing from the dashboard fails the gate.

READ MORE: Architecture, the four gates · apps/api/tests/unit/test_interlock_gate.py

ARTIFACT Machine twin

The per-metro JSON twin at /cities/<id>.json, generated at build time from the same registry entry as the page — coverage, divisions, submarkets, and feed detail included. Each file carries its provenance (generated_from), so hand-edited numbers are detectable by inspection.
